CARGAR MUCHO CON POSIBLES MEJORAS COMO LO SERÍA INPUT DESDE TECLADO POR EL USUARIO O COSAS POR EL ESTILO.

PEDIDOS, PARA REDUCIR EL PROGRAMA A LO ESCENCIAL; PORQUE, DE HECHO, YA ES BASTANTE EXTENSO.
